A few helpful details

Source comes from the camera

Make and model tags such as “Apple iPhone 14” become the source folder. A video without camera EXIF inherits the source when photos in the same folder agree on one camera. If they show multiple cameras, or no camera tags, the selected folder fallback is used.

Dates are shown honestly

The capture date is read from common JPEG, HEIC, TIFF, PNG, or WebP EXIF. If it is unavailable, the file modified date is used and labeled in the preview.

Files are moved locally

Applying a plan copies a file to its destination, checks its size, then removes the original. If a copy cannot be verified, the original stays in place.

Name collisions stay safe

Existing destination names get a numbered suffix in the plan. XMP, AAE, and THM sidecars move with matching media files.
